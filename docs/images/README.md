# README 소개 이미지

2026-11-15에 v0.9.69의 편집창, 미리보기, 기억지도를 촬영했습니다. 실제 앱 화면에 소개용 메모를 넣었으며, 개인 메모와 실제 업무 기록은 사용하지 않았습니다.

- `editor-preview.jpg`: [소개 메모](../examples/introduction.md)를 새 메모로 입력하고 목록을 닫은 뒤 편집·미리보기를 50:50으로 배치했습니다. Mermaid·LaTeX·표가 잘리지 않고 표시되는지 확인했습니다.
- `memory-map.jpg`: `Tests/D3ForcePreview.swift`의 가상 R-42 요청·설계 변경·검증 기록을 사용했습니다. 선택 메모 중심 보기에서 전체 맞춤을 적용하고, 관계 설명과 양쪽 원문 인용을 함께 표시했습니다.

촬영에는 임시 데이터베이스와 별도 설정을 쓰는 테스트 앱을 사용했습니다. 지도의 관계도 미리 넣어 둔 예시로, Ollama가 분석한 결과는 아닙니다. 촬영을 마친 뒤 테스트 앱은 정상 종료했습니다.

이미지는 창을 캡처한 그대로입니다. 테스트 앱이나 데이터베이스 파일은 저장소에 넣지 않았습니다.

다시 촬영할 때도 별도의 테스트 데이터를 사용하세요. 다이어그램과 수식이 잘리지 않는지, 원문 근거가 제대로 보이는지도 확인해 주세요. 창 크기와 테마에 따라 화면 배치는 달라질 수 있습니다.
