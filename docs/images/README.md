# README 소개 이미지

2026-11-15, v0.9.69의 실제 SwiftUI/AppKit 편집·미리보기·기억지도 UI를 격리된 QA 앱에서 캡처했습니다. AI가 생성한 앱 모형이 아닙니다. 화면 내용은 모두 소개용 예시이며 개인 메모나 실제 업무 기록은 사용하지 않았습니다.

- `editor-preview.jpg`: [소개 메모](../examples/introduction.md)를 새 메모로 입력하고 목록을 닫은 뒤 편집·미리보기를 50:50으로 배치했습니다. Mermaid·LaTeX·표가 잘리지 않고 표시되는지 확인했습니다.
- `memory-map.jpg`: `Tests/D3ForcePreview.swift`의 가상 R-42 요청·설계 변경·검증 기록을 사용했습니다. 선택 메모 중심 보기에서 전체 맞춤을 적용하고, 관계 설명과 양쪽 원문 인용을 함께 표시했습니다.

QA 앱은 임시 데이터베이스와 별도 환경설정을 사용합니다. 지도 관계는 검증용으로 미리 구성한 데이터이며 실제 Ollama 분석 결과가 아닙니다. 촬영 후 QA 앱은 정상 종료했습니다. 원본 창 캡처를 그대로 저장했으며 앱 결과물·데이터베이스는 저장소에 포함하지 않습니다.

다시 촬영할 때도 개인 데이터가 없는 격리 환경을 사용하고, 다이어그램·수식·원문 근거가 실제로 렌더링되는지 확인하세요. 화면 크기와 테마에 따라 배치는 달라질 수 있습니다.
