# 설치·업데이트·백업 안내

**v0.9.69 · 빌드 102** 기준 안내입니다. macOS 14 이상에서 설치할 수 있습니다. Apple 개발 도구가 필요하지만, GitHub에 로그인할 필요는 없습니다.

## 처음 설치하기

1. [v0.9.69 검증 후보 소스](https://github.com/Rayeonjin/MemoWeaver/archive/refs/tags/v0.9.69-qa.zip)를 내려받아 압축을 풉니다.
2. 터미널에서 `xcode-select --install`로 Apple 개발 도구를 설치합니다. 이미 설치되어 있으면 다음 단계로 넘어갑니다.
3. 터미널에 `cd `를 입력하고 소스 폴더를 끌어다 놓은 뒤 Enter를 누릅니다.
4. 아래 명령을 실행합니다. 앱이 실행 중이면 먼저 정상 종료합니다.

```bash
chmod +x *.sh
./install-v0.9.69.sh
```

빌드가 끝나면 앱이 설치되고 실행됩니다. 테스트까지 먼저 해 보고 싶다면 아래의 `--verify` 명령을 사용하세요. 위 설치 명령만으로는 테스트가 실행되지 않습니다.

## 설치하지 않고 검사·빌드하기

```bash
./install-v0.9.69.sh --verify
```

12개 테스트 묶음을 실행한 뒤 앱을 빌드합니다. 이미 설치된 앱은 그대로 두고, 새 앱을 `build/Release/MemoWeaver.app`에 만듭니다.

테스트 없이 빌드만 하려면 `./build.sh` 또는 `./install-v0.9.69.sh --build-only`를 실행하세요.

## 응용 프로그램 폴더는 어디인가요?

| 설치 전 상태 | 설치되는 위치 |
|---|---|
| 새로 설치 | `~/Applications/MemoWeaver.app` |
| 사용자 응용 프로그램 폴더에 기존 앱이 있음 | `~/Applications/MemoWeaver.app` |
| 공용 응용 프로그램 폴더에만 기존 앱이 있음 | `/Applications/MemoWeaver.app` |
| 두 위치 모두 기존 앱이 있음 | 사용자 폴더 우선, 공용 폴더의 앱은 그대로 남음 |

`~`는 현재 사용자의 홈 폴더입니다. Finder의 **이동 → 폴더로 이동…**에서 `~/Applications`를 입력하면 내 계정의 응용 프로그램 폴더가 열립니다. Finder 사이드바의 응용 프로그램은 보통 공용 `/Applications`입니다.

예전 이름인 `기억의 집.app`, `WorkOS.app`이 있어도 기존 설치로 인식합니다. 두 폴더에 앱이 모두 있다면 어느 쪽을 실행하는지 확인해 주세요.

설치할 폴더를 직접 고르려면 다음 명령을 사용하세요.

```bash
./install.sh --user   # 내 계정의 ~/Applications에 빌드·설치
./install.sh          # 공용 /Applications에 빌드·설치
```

공용 폴더에 설치할 때는 관리자 암호를 물을 수 있습니다. 위 명령은 기존 앱을 교체하기 전에 확인을 받습니다. 설치 후 바로 실행하려면 `--open`을 붙이세요.

## 기존 앱 업데이트하기

1. 새 버전의 소스를 별도 폴더에 풉니다. 기존 앱을 먼저 지우지 않습니다.
2. 메모를 저장하고 MemoWeaver를 정상 종료합니다.
3. 새 소스 폴더에서 데이터 백업을 실행합니다.
4. 아래 순서대로 테스트하고 새 앱을 설치합니다.

```bash
./backup-before-real-use.sh
./install-v0.9.69.sh --verify
./install-v0.9.69.sh
```

새 버전에서는 그 버전의 README에 적힌 설치 명령을 사용하세요. **설정 → 앱 정보 → 업데이트 확인**에서 새 버전이 나왔는지 볼 수 있지만, 다운로드와 설치는 직접 해야 합니다.

## 데이터와 백업 위치

- 메모·첨부·복구 자료: `~/Library/Application Support/WorkOS/`
- 데이터베이스: 위 폴더의 `WorkOS.sqlite`
- 백업 명령의 기본 저장 위치: `~/Documents/MemoWeaver Backups/`
- 이전 앱: 설치 폴더 안의 `.MemoWeaver.backup.날짜.프로세스번호.app`

앱 이름은 MemoWeaver지만, 기존 메모를 계속 읽을 수 있도록 데이터 폴더 이름은 `WorkOS`로 남겨 두었습니다. 이름을 바꾸거나 지우지 마세요. 앱을 업데이트해도 이 폴더는 그대로 유지됩니다.

백업 명령은 앱이 종료된 상태에서 WorkOS 폴더 전체를 압축하고, 압축 파일의 목록을 읽을 수 있는지 확인합니다. 메모 데이터베이스와 남아 있는 쓰기 기록(WAL), 첨부 파일, 복구 초안 등이 함께 들어갑니다. macOS 환경설정 전체까지 백업하지는 않습니다.

백업 파일은 별도 저장 장치에도 복사해 두세요. 처음 설치해서 데이터베이스가 아직 없다면 백업할 내용이 없어 명령이 중단됩니다.

## 이전 앱으로 되돌리기

설치 프로그램은 이전 앱을 숨김 파일로 보관한 뒤 새 앱을 넣고 서명을 확인합니다. 교체에 실패하거나 서명에 문제가 있으면 이전 앱으로 되돌리기를 시도합니다.

업데이트 후 직접 되돌릴 때는 앱을 정상 종료하고 데이터를 먼저 백업하세요. Finder에서 설치 폴더를 열고 `Command + Shift + .`으로 숨김 파일을 표시합니다. 현재 `MemoWeaver.app`을 별도 폴더에 보관하고, 원하는 `.MemoWeaver.backup.…app`을 **복사**하여 `MemoWeaver.app`으로 이름을 바꿉니다. 원래 백업은 남겨 둡니다.

이렇게 되돌리는 것은 앱 버전뿐입니다. 메모까지 예전 내용으로 돌아가지는 않습니다. 오래된 앱이 현재 데이터를 읽을 수 있는지 먼저 확인하세요. 메모를 복구하려면 따로 보관한 데이터 백업이 필요합니다.

## 설치가 멈췄을 때

- 실행 중인 앱이 있다는 메시지: MemoWeaver와 이전 이름의 앱을 정상 종료하고 재시도합니다.
- 개발 도구를 찾지 못함: `xcode-select --install` 설치 완료 후 `xcrun swift --version`으로 확인합니다.
- Swift 빌드 실패: 소스 폴더의 `build/Logs/swiftc-release.log`를 확인합니다.
- 검사 실패: 먼저 출력된 실패 항목을 확인합니다. `--verify`는 설치된 앱을 교체하지 않습니다.

어디까지 테스트했는지는 [v0.9.69 확인 항목](releases/MAC_ACCEPTANCE_v0.9.69.md)과 [자세한 테스트 기록](reviews/D3_MEMORY_MAP_2026-11-15.md)에서 볼 수 있습니다.
