# Attribution for derivative apps

This project takes a permissive approach to code reuse and a protective
approach to its original name and visual identity.

## Recommended attribution text (not an extra condition imposed on Apache 2.0)

English:

> This application incorporates portions of MemoWeaver, an open-source
> macOS notes project, licensed under the Apache License 2.0.

Korean transliteration is fine: "MemoWeaver (메모위버)".

In a derivative's `THIRD_PARTY_NOTICES`, `NOTICE`, README, documentation, or
other appropriate notice location, preserve the legally required original
copyright, Apache license and any relevant NOTICE content. The derivative's
own app name/icon must be distinct and must not imply that it is an official
MemoWeaver release.

**Important distinction:** Apache 2.0 does not require the developer to
publicize origin in a prominent splash screen or an About page. If the owner
wants a *mandatory* user-visible About screen credit beyond the standard
NOTICE/documentation requirement, a separate bespoke license would be needed
and reviewed for compatibility; this has NOT been introduced.

Brand reference and attribution are intentionally allowed; impersonation of
an official release is not. A trademark policy cannot remove independent
nominative/fair-use rights or substitute for actual registration.
