# v0.9.70 · 빌드 103

원문과 미리보기를 나란히 쓰는 방식은 그대로 두고, 편집 중 불편했던 네 곳을 손봤습니다.

- 긴 코드·수식 블록을 아래로 스크롤해도 일반 Markdown 색상이 섞이지 않습니다. 색상 분석은 백그라운드에서 처리합니다.
- 이미지 변환과 파일 저장을 백그라운드에서 처리합니다. 처리 중 다른 메모로 이동하거나 본문을 고치면 삽입을 취소합니다.
- 변경 이력에서 현재 본문과 이전 본문을 나란히 보고 복원할 수 있습니다. 복원 전 내용도 이력에 남습니다. 제목과 분류 등은 그대로 둡니다.
- 표 안에서 오른쪽 버튼을 누르면 행·열을 추가하거나 삭제하고 원문 간격을 정리할 수 있습니다. 셀 안의 코드와 이스케이프된 기호는 보존합니다.

표 편집, 본문 복원, 이미지 삽입은 실행 취소 한 번으로 되돌릴 수 있습니다. 한글을 조합하는 동안에는 본문 복원과 표 편집을 실행하지 않습니다.

설치 위치는 `/Applications/MemoWeaver.app`입니다. 기존 메모와 첨부 이미지 경로, 데이터 형식은 바꾸지 않았습니다.

실제 검증 결과는 [확인 항목](MAC_ACCEPTANCE_v0.9.70.md)에 기록합니다.
