# v0.9.70 편집기 확인 항목

2026-11-16, macOS / Apple Command Line Tools / arm64 환경에서 확인했습니다. 정식 안정판 인증이 아닌 검증 후보입니다.

## 통과한 검사

- 수정 전 v0.9.69 전체 12개 검사 묶음과 macOS 빌드.
- 수정 후 전체 12개 검사 묶음. 첫 실행의 마지막 네이티브 검사에서 테스트 코드의 DB 타입 이름 오타를 수정한 뒤 해당 검사와 앱 빌드를 다시 실행했습니다.
- 화면보다 500줄 앞에서 시작하는 코드·수식 블록의 색상 문맥, `$$`와 `\[ ... \]`.
- 한글·이모지·CRLF·이스케이프된 파이프·인라인 코드가 있는 표의 행·열 추가/삭제 및 간격 정리. 코드·수식 내부 표는 수정하지 않음.
- 표 편집, 본문 복원, 비동기 이미지 삽입의 한 번 실행 취소·다시 실행.
- 복원 전 현재 본문 체크포인트 보존, 제목·고정 상태 유지.
- 비동기 이미지 처리 중 본문 변경·메모 유효성 변경에 따른 취소와 생성 파일 정리.
- `setMarkedText`로 만든 조합 상태에서 전체 본문 교체와 화면 재구성 거부, 조합 원문 유지.
- 기존 설정/메모 왕복, 링크·역방향 링크, 고정, 긴 TXT 가져오기, 밝은/어두운 화면, 두 창 너비, 네 가지 패널 표시 조합.
- JSON·일정·노트북·첨부 백업 복원, 오프라인 미리보기, 지도 관계·근거와 d3 조작, 외부 라이브러리 고지 검사.
- 기본 `/Applications` 설치와 빌드/검사 모드의 설치 방지·실패 전달.
- 전체 앱 컴파일·링크·로컬 서명 및 서명 검증.
- 설치된 번들의 모든 파일과 빌드 결과 일치. 번들 ID `com.local.workos.notes` 유지.
- 설치 후 앱 실행과 기존 메모·원문/미리보기 표시 확인. 실행 후에도 DB 15개 테이블의 건수·내용 해시 일치.
- 설치 직전·직후 기존 데이터 파일 19개와 DB 테이블 15개의 해시 일치. 실제 메모는 테스트에 사용하지 않음.

## 직접 확인

격리된 임시 앱에서 이력의 현재/이전 본문 비교와 복원 버튼 동작을 확인했습니다. 실제 입력한 한글이 보이는 것까지 확인했으나, 첫 검사 창에서는 조합 상태 감지를 확인하지 못했습니다. 입력 알림과 공통 실행 루프 감시를 보완했고 감시 작동 로그를 확인했습니다. 실제 입력기의 조합 상태 재검사는 사용자 입력을 기다리고 있으며, 아직 통과로 기록하지 않습니다.

Ollama 관계 판단 품질, 알림 권한·실제 수신, 트랙패드 핀치는 이번 편집기 변경과 별개인 기존 수동 확인 항목입니다.
