# 스크립트 안내

일반적인 빌드와 검증은 저장소 최상위에서 실행합니다.

```bash
./install-v0.9.64.sh --verify
```

현재 설치 스크립트가 지원되는 회귀 검사 묶음을 선택해 실행합니다.
개별 검사가 필요하면 최상위에서 새 경로를 사용하세요.

```bash
./scripts/tests/test-review-stability.sh
./scripts/tests/test-third-party-licenses.sh
```

| 폴더 | 용도 |
|---|---|
| `tests/` | 현재 및 과거 버전의 테스트 실행 스크립트 |
| `renderers/` | 개발용 렌더러 준비·이전 도구 |
| `diagnostics/` | 클립보드 등 진단 도구 |

과거 버전 스크립트에는 당시 버전·구조를 검사하는 조건이 있으므로
모든 과거 검사가 현재 버전에 적용되는 것은 아닙니다. 현재 지원되는
검사는 `install-v0.9.64.sh`의 목록을 기준으로 합니다.

렌더러 도구는 배포된 JavaScript를 교체할 수 있는 개발용 작업입니다.
일상적인 메모 작성이나 소스 빌드에는 실행할 필요가 없습니다.
