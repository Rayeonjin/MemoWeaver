# 과거 설치 스크립트

`legacy/`에는 v0.9.64~v0.9.68 때 사용한 설치 스크립트를 보관합니다.
현재 버전을 설치할 때는 저장소 최상위의 `./install-v0.9.69.sh`를 사용하세요.

과거 스크립트도 현재 소스를 빌드합니다. 예전 버전의 앱을 받거나 복원하는 명령이 아닙니다. 당시 버전을 빌드하려면 해당 Git 태그나 소스 ZIP을 사용하세요.

도움말은 다음처럼 확인할 수 있습니다.

```bash
./scripts/install/legacy/install-v0.9.68.sh --help
```

폴더 이동 후에도 실행 위치와 관계없이 저장소 최상위를 찾도록 경로를 수정했습니다. 과거 버전의 테스트에는 당시 버전·구조를 전제로 한 항목이 남아 있습니다.
